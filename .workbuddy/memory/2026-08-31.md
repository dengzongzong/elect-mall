  - `nginx/elect-mall.conf`：nginx 配置（商城+后台两个 server 块），末尾附 php-fpm 替换片段。
  - `systemd/elect-mall-backend.service`：PHP 后端常驻服务（php -S，含 DB 环境变量）。
  - `deploy.sh`：一键部署（拉代码→构建→校验 nginx→重载服务）。
  - `DEPLOY.md`：完整部署文档（环境要求、首次部署、日常更新、排错、安全检查清单）。
