## 商品阶梯价（录入、展示、下单计费）
- 需求：商品详情页展示阶梯价；后台可提前录入阶梯价；下单按购买数量匹配阶梯价计费。
- 数据库：product 表新增 `tier_prices` JSON 字段，同步 `install.sql` / `mall_db_schema.sql`。
- 后端 `crmeb/public/adapter.php`：
  - `product/add`、`product/update` 接收 `tierPrices` 数组并 JSON 化存储。
  - `product/{id}`、`product/page`、`product/recommend` 返回时 JSON decode `tier_prices`。
  - `order/create` 在锁定库存后，根据购物车数量匹配阶梯价（按 `min_qty` 降序取首个满足条件的价格），无阶梯价回退到基础价。
- 前端：
  - `admin-web/src/views/Product.vue`：新增/编辑表单增加阶梯价动态录入（数量+单价，可增删）；修复编辑按钮未绑定 `handleEdit` 的问题。
  - `mall-web/src/views/ProductDetail.vue`：展示「基础价 / 当前单价 / 阶梯价格表」，数量改变时实时计算当前单价与合计。
- 验证：
  - API：设置商品1 阶梯价 1+/0.05、100+/0.04、1000+/0.03；下单 qty=50/100/1000 分别得到 2.5/4/30，金额正确。
  - 构建：admin-web、mall-web `npm run build` 通过。
  - UI：Playwright 验证前台详情页正确展示阶梯价表；后台新增商品对话框可添加阶梯价行。
